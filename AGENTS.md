# Project information

- Stack: Next.js 15 App Router, React 19, TypeScript, Tailwind CSS 4, Radix Dialog, Lucide, Prisma 6. Local development uses SQLite; Vercel production uses Neon PostgreSQL.
- Install with `npm install`; initialize the local database with `npm run db:push`; start with `npm run dev` on port 3000. Set local `DATABASE_URL` to `file:./pulse.db`.
- Verification: `npm test` (nine date/recurrence/analytics/settings tests), `npm run typecheck`, `npm run build`, and `npm audit --omit=dev`.
- Production requires `APP_USERNAME` and `APP_PASSWORD` for the single-user HTTP Basic authentication middleware. Serve production traffic over HTTPS. Development does not require credentials. Do not print or commit credentials.
- Vercel project: `akfotos/pulse-reminder-app`; connected GitHub repository: `akfotos/pulse-reminder-app`. Neon free resource: `pulse-reminder-db`, London region.
- Production schema is `prisma/production/schema.prisma`. `npm run vercel-build` generates the PostgreSQL client, applies versioned migrations using `DATABASE_URL_UNPOOLED`, and builds Next.js. Runtime traffic uses pooled `DATABASE_URL`. Never use destructive database reset commands for deployment.
- Local schema is `prisma/schema.prisma`; the database is `prisma/pulse.db`. After running the production generator locally, run `npm run db:generate` to restore the SQLite client before starting local development.
- This is a single-user personal workspace, not a multi-tenant application. Development seeds example reminders when settings do not exist; production starts empty and initializes settings using an upsert. Existing local reminders are not automatically copied to production; use CSV export/import.
- Notifications require `RESEND_API_KEY`, a verified `EMAIL_FROM`, and `CRON_SECRET`. The daily cron route is scheduled at 08:00 UTC in `vercel.json`; the weekly digest uses the day selected in Settings. Email notes honor `includeNotes`. Real delivery requires provider credentials and has not been tested without them.
- Import formats: first worksheet of XLSX, comma/tab-separated CSV or text, and comma/tab-separated text extracted from DOCX. Parser limit: 5 MB and 500 rows. Vercel request-body limits also apply; use smaller files. Import preview does not write data until confirmed.
- Settings and analytics are separate components. Preferences include workspace names, theme, motion, density, calendar week start, date format, notification defaults, digest day, notes privacy, and document warning windows. Analytics counts every recurring occurrence in a selected 7/30/90-day window and shows actual zero values.
- Browser verification can use Playwright with the system Chrome channel. Dashboard and settings were tested at 320, 390, 768, 1024, and 1440 px with no horizontal overflow. Restore settings after tests; only delete test reminders created by the test itself.
